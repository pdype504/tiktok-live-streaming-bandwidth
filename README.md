## 带宽到底要多少：手机 5M、电脑 10M 的由来

单台手机直播配 5M 能跑起来，单台电脑直播建议 10M 起，这组数字来自直播链路本身的结构差异，而不是商家随口报的。

手机走 TikTok App 直推，推流参数由平台和手机根据实时网络状况自适应，画质和码率会自动下调，链路简单，5M 稳定上行够用。电脑走 LIVE Studio 或 OBS，分辨率、帧率、视频码率、音频码率、编码器全部自己设，1080P 30FPS 和 1080P 60FPS 的上行需求能差一倍，所以起步就得 10M。

按场景对照：

| 直播场景 | 建议上行带宽 | 说明 |
| --- | --- | --- |
| 单台手机，720P 常规带货 | 5M 起步 | 追求稳可加到 10M |
| 单台电脑，720P 推流 | 4Mbps 以上 | LIVE Studio 常见配置 |
| 单台电脑，1080P 30FPS | 10Mbps 以上 | 建议 10–20M 留余量 |
| 单台电脑，1080P 60FPS | 15–20Mbps | 画面变化快时码率更高 |
| 多台设备同时开播 | 台数 × 单机需求 + 冗余 | 3 台手机不建议共享 5M |

几份公开资料的带宽口径不完全一致，差异来自“视频码率”和“含冗余的线路带宽”两种算法。有服务商按 1080P 稳定 6–10Mbps 上行给建议，也有服务商说 1080p 5Mbps 就够。前者把抖动和突发码率算进去了，后者说的是纯码率。做采购决策时用前一种口径更安全，因为直播掉帧的代价比多买 5M 带宽高得多。

多设备场景不能套用单机数字。3 台手机同时开播，每条线路按 5M 算就要 15M 可稳定使用的带宽，再加上 20%–30% 冗余，一条 5M 的线撑不住。这里说的“可稳定使用”指直播全程能维持的上行，不是测速页面偶尔跳出来的峰值。

## 带宽够了还是卡：IP 属性、地区匹配和回程抖动

直播卡顿里，带宽不足只占一部分。另外三个变量在套餐参数表上看不出来，却更常引发问题。

**IP 属性。** TikTok 会判断 IP 是住宅宽带还是机房地址。数据中心 IP 被识别为机器流量的概率高，推流后播放量归零或限流是常见结果。行业里通行的排序是住宅 IP、双 ISP IP 优于纯数据中心 IP，双 ISP 兼具住宅特征和线路稳定性，是目前 TikTok 直播的主流选择。WePC 全线标的是“双 ISP”和“静态家宽”，这正是它跟普通便宜 VPS 的主要差别。

**IP 纯净度。** 同一个 IP 被多少账号用过、有没有违规记录，直接影响新号起量。一个被前用户跑过黑产或群控的 IP，换谁用都受牵连。

**地区匹配。** 做美区就用美国 IP，做东南亚就用当地 IP。归属地和运营市场不一致，推荐权重会被压低。

**回程延迟与抖动。** 国内到美西走公网 BGP，延迟常在 180–250ms 且波动大；走 IPLC 类专线能压到 120ms 上下；沪日方向约 25ms；广港专线段能到 3ms 级别。这几个数字是行业量级参考，不是你实际会看到的端到端延迟。所谓“3ms”指广州入口到香港出口的专线段，你家宽带到入口那一段要另算。WePC 美国系列用 4837 和 9929 回程优化线路，属于优化型公网，不是点对点专线，延迟表现会比裸 BGP 好，但别指望专线级别的抖动控制。

**账号与 IP 的配比。** 行业经验是 1 个 IP 配 1 个直播账号，最多再加 2–3 个养号账号。同一 IP 下登录账号过多，容易触发风控连带封号。WePC 每个套餐给 1 个 IPv4，意味着一个套餐服务一个主力直播账号，多账号运营就得多买。

## 1.5TB 双向流量能播多久：算完再下单

这是最容易被忽略的一项。WePC 澳洲页面明确写“2TB 双向流量”，美国系列标 1.5TB 并对超量限速 3M。双向计费意味着上行推流和下行数据都计入配额，直播恰恰是上行消耗最大的场景。

按 1080P 6Mbps 上行估算：每小时上行约 2.7GB，双向计费下按 5.4GB 计。1.5TB 约等于 1536GB，够播约 280 小时，折合每天 9 小时出头。2TB 约 2048GB，够播约 370 小时，折合每天 12 小时。

换成 1080P 10Mbps：每小时上行 4.5GB，双向 9GB，1.5TB 只够 170 小时，2TB 够 227 小时。

单机手机直播 5Mbps：每小时上行 2.25GB，双向 4.5GB，1.5TB 能撑 340 小时左右。

上面是纯推流的理论值，实际还有后台同步、素材上传、远程桌面、监控画面等杂项流量。超量后不是停机而是限速到 3M，这个设计对直播的杀伤力比想象中大：限速状态下 1080P 推流会直接掉画质，勉强维持也会频繁缓冲。日播时长超过 8 小时的团队，要么选 2TB 的澳洲线，要么提前算好流量重置方案。

## 常见问题

**5M 专线到底能不能直播？**
能，前提是这 5M 是直播全程可稳定使用的上行，而不是测速时的瞬时峰值。单台手机、720P、真人出镜带货这类场景，5M 够；一旦上 1080P、多机位或多设备共享，就要往上加。

**一台设备能挂几个 TikTok 账号？**
直播账号建议 1 个 IP 对 1 个，养号账号最多再加 2–3 个。同一 IP 下登录账号过多容易触发风控，一个号出问题会连带其他号。WePC 每个套餐 1 个 IPv4，多账号就是多买几条。

**1080P 直播要多少上行？**
按码率算 6–10Mbps 上行，按含冗余的线路带宽算建议 10–20Mbps。30FPS 和 60FPS 需求不同，画面变化越频繁、码率越高，余量要留得越多。

**流量用超了怎么办？**
WePC 美国系列超量后限速 3M，不停机。限速状态下 1080P 推流会明显掉画质，等于变相逼你升级或重置流量。下单前按每天直播小时数乘码率估一遍，别等月中才发现不够。

**多久能看出线路好坏？**
一两天。用真实 TikTok 直播环境跑一场完整时长的直播，看掉帧、缓冲、观众端卡顿反馈，比任何测速页面都准。测速只能证明那一刻的带宽，证明不了持续推流时的抖动和丢包。

**IP 归属地能改吗？**
不能跨地区随便改。买之前就按目标市场选对应节点，美区账号买美国机器，东南亚账号买新加坡或越南机器，换机器等于换 IP，账号环境会断。
